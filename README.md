# 比率道場

線の上の比率(A:B = 1:2 など)を目分量で当てる練習ゲームです。
お絵描きに必要な比率の感覚を、クイズ形式で鍛えます。

## 遊んでみる

ブラウザですぐ遊べます。

https://tademushi2004.github.io/hiritsu-dojo/

PCのブラウザとスマホの実機で動作を確認しています。

## 遊び方

- 1ラウンドは10問です。
- 「A:B = 1:2 の位置にカーソルを置いてください」のように比率が出題されます。
- 線の上をマウスまたは指でなぞって、カーソルを動かします。
- 「決定」を押すと、評価、誤差、あなたの位置、正解の位置が表示されます。
- 「次へ」で次の問題に進みます。
- 10問目の後は「結果を見る」で最終結果が表示され、「もう一度遊ぶ」で新しいラウンドを始められます。
- 出題中は、目盛りや補助線などのヒントは表示されません。

## 評価とスコア

誤差は、正解位置と回答位置の差(線に沿った長さ)を、線の全長で割って100を掛けた値(%)です。

| 評価 | 誤差 | 得点 |
| --- | --- | --- |
| Perfect | 2%以内 | 100点 |
| Great | 2%を超え5%以内 | 70点 |
| Good | 5%を超え10%以内 | 40点 |
| Miss | 10%を超える | 0点 |

1ラウンドの満点は1000点です。

## 特徴

- 出題される比率は、1:1、1:2、1:3、2:3、3:5 と、その向きを入れ替えたもの(2:1、3:1、3:2、5:3)の全9種類です。
- 直前の問題と同じ比率は続けて出ません。
- 線の種類は、水平の直線、斜めの直線、曲線の3つです。
- 曲線は3次ベジェ曲線で、200本の線分に分けて近似し、その長さで判定します。
- 線は問題ごとに新しく作られ、カーソルの初期位置もランダムです。
- マウスとタッチの両方で操作できます。
- 評価は色に加えて、文字とアイコンの形でも区別できます。
- 最終結果には、評価ごとの回数、今回の得点、自己ベストが表示されます。

## ローカルでの動かし方

ビルドは不要で、`index.html` をブラウザで開くだけで動きます。

## 技術構成

HTML、CSS、JavaScript のみで作られており、外部ライブラリは使っていません。

### ファイル構成

- `index.html`: 画面の構造
- `style.css`: 見た目
- `script.js`: 出題、判定、得点、自己ベストの処理

## データの扱い

自己ベストは、お使いのブラウザのlocalStorageにだけ保存され、このアプリから外部へ送信されません。
